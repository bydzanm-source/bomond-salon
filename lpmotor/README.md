# Bomond

Одностраничный сайт студии красоты. React и TypeScript отвечают за интерфейс, Vite собирает статические файлы, а React заранее формирует HTML. Прайс, контакты и SEO-метаданные доступны без JavaScript.

## Локальный запуск

Требуются Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Для просмотра той же сборки, которую получает статический хостинг:

```sh
npm run build
npm run preview -- --host 127.0.0.1
```

Для браузерных проверок установите Chromium командой `npx playwright install chromium`, затем выполните `npm run build && npm test`.

## Где вносить правки

| Что меняется                                    | Где искать                        |
| ----------------------------------------------- | --------------------------------- |
| Прайс, услуги, мастера, отзывы                  | `src/content/`                    |
| Телефон, адрес, часы работы и ссылки            | `src/content/studio.ts`           |
| Порядок секций и плавающая кнопка записи        | `src/app/App.tsx`                 |
| Разметка и состояние раздела                    | `src/sections/`                   |
| Стили секций, общая тема и сезонное оформление  | `src/styles/`                     |
| Подключение к Telegram Mini App                 | `src/integrations/useTelegram.ts` |
| Поисковый сниппет, Open Graph и разметка салона | `src/app/server.tsx`              |
| Предварительный рендеринг и служебные SEO-файлы | `scripts/prerender.mjs`           |

Номера категорий прайса входят в ссылки вида `/#price-4`. При редактировании сохраните существующие идентификаторы и проверьте связь карточек услуг с категориями.

## Публикация на LPmotor

`npm run build:mottor` создаёт `.mottor/payload.json` и `.mottor/preview.html`. Первый файл содержит HTML, CSS и JavaScript для десяти существующих секций LPmotor, а также общий код сайта для Telegram и плавающей записи. Второй файл можно загрузить на LPmotor в качестве стенда. Он помечен `noindex`.

1. Проверьте `preview.html` на компьютере и телефоне. Пройдите навигацию, прайс, отзывы, переключение темы и переход к записи.
2. В LPmotor сохраните снимок текущих секций и общего кода в `backups/`.
3. Сопоставьте десять записей из `payload.json` с действующими секциями в порядке `src/app/sections.ts`. Сохраните их через `section_content_update` с существующими идентификаторами и текущими ревизиями. SEO-поля страницы обновлять не требуется.
4. Сохраните только `code` из `payload.json` через `site_seo_update`, затем вызовите `page_deploy`. Проверьте рабочий домен, включая `robots.txt`, `sitemap.xml` и адрес записи.
5. Для отката верните сохранённые секции и общий код и вызовите `page_deploy` повторно.

LPmotor хранит готовый HTML каждой секции. Один бандл React, расположенный в секции шапки, подключает интерактивность всех секций. Правьте исходники в этом проекте и пересобирайте пакет. Фотографии и шрифты берутся из библиотеки LPmotor, за запись отвечает DIKIDI.
